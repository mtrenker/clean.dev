# Identity specimens (issue #124, experiment 1)

Three deliberately different identity directions for clean.dev, each rendered as a single static page with the same real content. The goal is to prune, not to pick a winner by vote: each direction has to pass the removal test (if the logo and nouns disappeared, would the page still express something specific about clean.dev?).

- `content.md`: the shared content. Every specimen uses it verbatim.
- `a-margin/`, `b-schematic/`, `c-letter/`: one direction each. `BRIEF.md` is the constitution the direction was built from, `NOTES.md` is the builder's record (decisions, contrast math, self-critique), `index.html` + `styles.css` is the specimen, `screenshots/` holds captures at 360, 768, 1280 and 1920 px.

Open any `index.html` directly in a browser. No build step.

These are experiments, not production design. Nothing here is accepted until it is recorded as a decision on issue #124.
