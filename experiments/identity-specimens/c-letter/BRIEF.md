# Direction C: Letter

## Thesis
This should feel like a well-set letter from someone with nothing to hide: direct, confident, nearly bare, never cold. It takes "nothing without a stated reason" literally, because the reader has seen every decorated site and this one earns attention through scale, voice and one living sentence.

## Emotional target
Honest, direct, grounded. Must not feel unfinished, like a default browser page, or like generic minimalism.

## Center and intensity
Reading and conversation. Expression exists only in typographic scale and in the live sentence. Everything else is as plain as it can be while remaining clearly designed.

## Constructive grammar
- Surface: white or the nearest off-white. One surface, nothing else.
- Color: near-black text and exactly one accent, used only for links and the values in the live sentence. State the choice in NOTES.md.
- Type: one typeface family for everything, chosen for character at very large sizes and comfort at text size (candidates: Inter is explicitly excluded as too default; consider Instrument Sans, Geist, Söhne-like alternatives with an open license, or a text-friendly grotesk like Public Sans). Load it, do not assume. Exactly two sizes carry the page: display (as large as the viewport comfortably allows, using clamp()) and text. Small print (metadata, footer) is a third size, used sparingly, never below 14px. Measure 55 to 65 characters.
- Space and density: extreme spacing discipline. Large, consistent vertical gaps. Whitespace is the only grouping mechanism.
- Geometry: none. No rules, no borders, no cards, no radius, no shadows.
- Imagery: none. No icons, no drawings. The figure is rendered as prose and a plain table.
- Motion: none in the static specimen. Note in NOTES.md how the live sentence would animate value changes under a reduced-motion equivalent.
- Voice: first person, short sentences, plain words.

## Signature
1. The live sentence. The figure becomes a sentence with its values visually distinct (accent color plus a non-color cue such as underline or weight): "A team of 5 developers and 1 reviewer has 14 changes waiting for review. Add 2 developers and 20 changes wait." In the static specimen, render both the before and after sentence; in production the values would be adjustable and the second sentence would update. The plain table from content.md follows as the text equivalent.
2. Scale contrast. Headlines very large, body text calm; nothing in between.
3. A one-line status at the top of the page (from the content's status line), set in text size, which is the only "chrome" besides navigation.

Memory hook: the live sentence.

## Prohibitions
- No decoration of any kind. No more than three type sizes on the page. No icons. No color beyond the accent. No uppercase tracking. No buttons; links are links.
- Navigation and footer are plain inline lists of links.

## Removal test
If the name and nouns vanished, the page should still read as "someone speaking plainly who lets you change the numbers". If it reads as "minimal template", the direction has failed and NOTES.md should say so.
