Install it

send a real test afterwards

Proton Mail

If Proton is your sending client: Settings → Identity and addresses → edit signature. Prefer the source/HTML view when available and paste the raw HTML. If your version has no source view, use Copy rendered signature and paste into the rich editor.

Gmail web

Settings → See all settings → General → Signature. Use Copy rendered signature, then paste. Gmail normalizes markup on save, so send a message and inspect that result.

Outlook for Windows

For classic Outlook, save a complete UTF-8 .htm file under %APPDATA%\Microsoft\Signatures\; editing there avoids Word mangling the table. New Outlook may require rendered paste instead.

Outlook on the web

Settings → Mail → Compose and reply. Use Copy rendered signature and paste into the signature editor.

Apple Mail on macOS

Mail → Settings → Signatures. Uncheck “Always match my default message font,” then paste rendered. If formatting is lost, use the known *.mailsignature edit-and-lock workaround.

iOS Mail

Settings → Apps → Mail → Signature. Paste rendered and remove any shake-to-undo formatting reset if prompted. iOS signatures do not reliably sync from macOS.

Plain-text companion

ASCII / no signature separator

Set this wherever your client offers a separate plain-text signature. It avoids the conventional -- prefix because some clients trim everything after it.
